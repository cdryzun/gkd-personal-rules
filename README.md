## 0. 范围

本订阅含 5 个应用、12 个应用规则组，没有全局规则。需要用户主动授权 GKD 无障碍，不需要 root 或 Shizuku。无障碍能够读取窗口内容并执行点击，规则可能误触，不能保证适配所有应用版本。

| 应用 | 组数 | 操作范围 |
| --- | --- | --- |
| 京东 | 4 | 开屏、悬浮广告、广告弹窗、横幅 |
| 淘宝 | 3 | 开屏、广告弹窗、悬浮／卡片／横幅 |
| 钉钉 | 2 | 开屏、消息列表顶部广告 |
| 网易云音乐 | 2 | 开屏、局部卡片广告 |
| YouTube | 1 | 点击出现的“跳过广告”按钮，不移除不可跳过广告 |

不含微信、支付宝、银行应用及自动登录、支付、权限确认、安全提示关闭等操作。使用控件点击，不使用坐标点击、返回键或多步链式操作。四个开屏组限制为应用进入后 9 秒内最多点击一次；其他组限制见 JSON，不能把这些限制当成无误触保证。

## 1. 导入与更新

公开发布后，在 GKD 的添加订阅入口输入：

```text
https://raw.githubusercontent.com/cdryzun/gkd-personal-rules/main/subscription.json
```

手机保存规则后在本地执行，不依赖电脑或临时服务在线。网络仅用于导入和后续检查更新。先保持自动更新关闭，手动更新并逐应用观察；仓库提供更新地址不代表已在手机开启自动更新。

订阅 ID 保持 `2026102704`，版本提升到 2，以便替换此前临时导入的 v1。导入后必须确认只保留一份有效规则，不能假定相同 ID 的链接修改会自动正确完成。
